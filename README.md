A fan game inspired by **Yu-Gi-Oh! Forbidden Memories**, developed in **Unity**.

## About

**Between Memories** aims to recreate and expand the gameplay of *Yu-Gi-Oh! Forbidden Memories* while introducing mechanics inspired by modern Yu-Gi-Oh! games.

### Current Features

* Local Multiplayer
* Multiple Duel Modes
* Guardian Star System
* Fusion System
* Ritual Summoning
* Custom Card Effects

## Game Modes

### Classic Mode

A faithful recreation of the original *Yu-Gi-Oh! Forbidden Memories* gameplay.

* Starting Hand: 5 Cards
* Draw until returning to your starting hand size during the Draw Phase
* Play only 1 card per turn

### Normal Mode

Traditional Yu-Gi-Oh! gameplay adapted for Between Memories.

### Speed Duel Mode

A faster-paced duel experience with streamlined rules.

### Duelist Kingdom Mode

A game mode inspired by the **Duelist Kingdom** arc from *Yu-Gi-Oh! Duel Monsters*.

## Installation

1. Download the latest release.
2. Extract the files.
3. Launch `YGO Between Memories.exe`.
